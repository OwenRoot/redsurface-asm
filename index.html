Enter a domain, pick a mode and run a sweep. Results appear here, with the worst problems first.

What a sweep checks

  • Which hostnames exist for the domain, based on public certificate logs and DNS.
  • Which software versions the servers announce, matched against known vulnerabilities and CISA's list of actively exploited ones.
  • Whether HTTPS, certificates and security headers are set up properly.

Results are encrypted on the server and checked for tampering in your browser before they are shown.
